# Release notes

Newest first. Each release is cut as `release/X.Y.Z` (docs/branching-and-release.md).

## 0.2.0 (2026-11-27), UX test build

What to try, signed in:

- **Fix a pub.** Open a pub and tap Fix. Every field people can correct is there, in
  sections: rename it, set its website or phone, answer "what's there", change its type,
  report a Guinness price, set quiz and karaoke nights, or mark it closed with the year
  and what it became. Tap Done to go back.
- **Opening hours.** In Fix, Edit beside the hours: a day at a time, split shifts,
  "Late" for no fixed close, "Same every day".
- **Last orders and kicked out.** "It just happened", or pick the night and time.
  Past midnight counts as the night before.
- **Garden closing time** on the same time picker.
- Searching with the sheet pulled down now shows the results.

Known gaps: history (former names) can't be edited yet, and there's no 🎲 random handle.
